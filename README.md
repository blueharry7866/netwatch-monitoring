# netwatch-monitoring
NetWatch: Network monitoring &amp; alerting in Python — ping, TCP &amp; HTTP checks, SQLite history, one alert per outage (email/webhook), live dashboard &amp; uptime reports. Zero dependencies.

## Initial Git setup

```bash
git add .
git commit -m "Initial commit: NetWatch network monitoring & alerting"
git branch -M main
git remote add origin https://github.com/blueharry7866/netwatch.git
git push -u origin main
```
